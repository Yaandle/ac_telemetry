================================================================================
WHAT EACH FLAG DOES
================================================================================

--lr        Train Linear Regression (baseline)
--mlp       Train 3 MLP architectures (64-32, 128-64-32, 256-128-64)
--ga        Train Genetic Algorithm on episode data
--dql       Train Deep Q-Learning on transitions
--all       Train everything (default if no flags given)


================================================================================
WHY THIS IS BETTER
================================================================================

OLD WAY (3 separate scripts):
  1. python telemetry_analysis_terminal.py --ml
  2. python ml_trainer.py
  3. python train/train_ga.py
  4. python train/train_dql.py

  Problem: Had to run 4 separate commands, datasets generated 3 times

NEW WAY (2 scripts):
  1. python telemetry_analysis_terminal.py --ml    (prepare ALL datasets ONCE)
  2. python ml_trainer.py --all                   (train ALL models)

  Benefits:
  ✅ Datasets prepared only once
  ✅ All models use SAME normalization
  ✅ Single command to train everything
  ✅ Or train specific models with flags
